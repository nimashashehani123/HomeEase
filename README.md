# HomeEase – On-Demand Home Services Platform


## **📌 Description**
HomeEase is a digital marketplace linking homeowners with trusted local service professionals. Book, manage, and pay for home services (cleaning, plumbing, electrical, etc.) seamlessly through a unified platform.


---

### **✨ Key Features**
Role-Based Access: Separate interfaces for Customers, Service Providers, and Admins.

Service Booking: Customers can browse, book, and schedule services in real-time.

Provider Profiles: Verified professionals with ratings, reviews, and service history.

Live Tracking: Track provider arrival times via GPS (optional).

Secure Payments: In-app payments with invoices/receipts.

Admin Dashboard: Manage users, services, bookings, and disputes.

### **🛠️ Technologies Used**
Frontend: HTML5, CSS3, JavaScript, Bootstrap, AJAX

Backend: Java, Servlets, JSP

Database: MySQL (Stores user data, services, bookings, payments)

APIs: Google Maps API (location tracking), Stripe/Razorpay (payments)

Tools: IntelliJ IDEA, Maven, Git
